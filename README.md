# Tooth BUDDS — online demo

One file: `index.html`. Made-up data, no login, no backend. Upload this folder to any static host.

Built from `codex-demo/index.html` (Codex's design, chosen by MiQuel on 2026-11-10) plus the changes from that call, added by Claude Fable 5.2. `codex-demo/` is untouched. The added code sits at the end of the script under the comment "Changes after the 10 Nov 2026 call".

Links:
- `/` — MiQuel's view
- `/?role=office` — Carolina's view
- `/?role=field` — a hygienist's view
- `/?view=parent` — the parent phone form
- `/?show=money` (also `insurance`, `documents`, `reports`, `review`, `child`, `pay`) — opens on that screen

Search engines are asked not to index the page. School names and staff first names are real; every child, figure and claim is invented.
